# 백엔드 및 AI 응용 개발 포트폴리오

[포트폴리오 보기](https://hyungminyoon1.github.io/)

첫 화면에는 빛이 여러 경로로 흐르는 조형이 보이며, 상단의 Y 마크 옆에 이름을 표시합니다. 상단에서 소개, 프로젝트, 학습 기록을 선택합니다. 프로젝트 목록은 목표와 쓰임을 짧게 설명하고, 상세 글은 제가 맡은 일과 구현 과정, 결과와 측정 조건을 다룹니다. Nodease와 험비 연구는 공개 GitHub 저장소로 연결하며, StoreOps는 비공개 상태를 표시합니다.

## 로컬 실행

Node.js 20 이상이면 별도 라이브러리 설치 없이 실행할 수 있습니다. 저장소 디렉터리에서 다음 명령을 실행합니다.

```sh
npm run build
npm run check
npm run audit
npm run preview
```

Windows PowerShell에서는 `npm` 대신 `npm.cmd`를 사용할 수 있습니다. 로컬 주소는 `http://127.0.0.1:4177/`이며 서버 종료는 `Ctrl+C`입니다. 파일 수정 후 다시 빌드하고 브라우저를 새로고침합니다.

## 구성과 공개 범위

- `index.html`은 검색과 업무 흐름을 빛으로 표현한 첫 화면입니다.
- `about/`에는 자기소개, 학적을 표시한 프로필 사진, AI 도구 사용 범위가 있습니다.
- `projects/`에는 세 프로젝트의 개요와 각 상세 글이 있습니다.
- `learning/`은 AI Helpdesk 학습 기록과 WEB LAB으로 연결합니다.
- `assets/`에는 화면 전환 스크립트, 스타일, 아이콘과 검토한 이미지가 있습니다.
- `evidence/storeops-summary.json`: 기존 검증 보고서의 조건과 결과 요약
- `scripts/public-files.mjs`: 사이트에 배포하는 파일 목록
- `scripts/publication-files.mjs`: 공개 저장소에 포함하는 파일 목록
- `.github/workflows/pages.yml`: 검사와 GitHub Pages 배포

작업 메모, 변경 전 사본과 화면 검수 자료는 `docs/`, `.local/`, `output/` 등에 로컬로 보관하며 Git과 배포 대상에서 제외합니다. 사용자가 허용한 이름(윤형민), 프로필 사진과 서울사이버대학교 컴퓨터공학과 학습 사실만 소개합니다. 프로필 사진은 공개를 승인한 기존 PNG입니다. 앱 화면에는 시연용 자료를 사용하며 이미지에 포함된 부가 메타데이터를 검사합니다. 원본 이력서·사진 파일, 연락처, 학번·학년·성적 등 추가 학적 정보, 교범 PDF 전체, 발표 원본, 전체 로그나 계정 정보는 포함하지 않습니다. GitHub 계정과 공개 프로젝트 링크를 연결하므로 익명 사이트는 아닙니다.

## 화면과 이미지

홈의 유리판과 광섬유는 자료를 찾고 여러 작업을 연결하는 과정을 표현한 AI 생성 이미지입니다. 가로와 세로 구도에서 광섬유의 밝은 부분을 원본 좌표에 맞춰 작은 타일로 저장했습니다. 빛은 이 타일 위를 서로 다른 속도로 흐릅니다. 커서를 움직이면 잔상이 남고 클릭과 드래그에 따라 빛이 퍼집니다. 하단 버튼으로 두 효과를 함께 멈추거나 재생할 수 있습니다. 운영체제에서 동작 줄이기를 선택하면 정지 화면으로 열립니다.

Nodease에는 팀 발표 당시의 워크플로 편집 화면을, StoreOps에는 합성 데이터로 실행한 앱의 승인 화면을 사용했습니다. 험비 연구의 상세 글에는 차량 사진과 연구에 사용한 교범 표지를 함께 실었습니다. 차량 사진은 미 육군 Ethan Scofield가 촬영했으며 DVIDS에 공개 도메인 자료로 표시되어 있습니다. [차량 사진 원본](https://www.dvidshub.net/image/6823052/humvee) · [교범 판본과 출처](https://github.com/HyungminYoon1/hmmwv-rag-experiment/blob/v2026.10.08/docs/data-sources.md)

각 화면은 직접 열 수 있는 정적 HTML입니다. 일반 내부 링크를 누르면 동일 출처의 페이지를 가져와 본문과 제목을 바꿉니다. JavaScript 없이도 같은 주소로 열리고, 예전 홈의 섹션 주소는 JavaScript가 해당 화면으로 연결합니다.

## 검사와 배포

`main`에 푸시하면 GitHub Actions가 빌드, 문서 구조/링크 검사와 공개 정보 점검을 실행합니다. 검사를 통과한 `dist/`만 Pages에 올립니다. 저장소 루트 전체를 웹사이트로 제공하지 않습니다.

개인정보와 비밀값 점검은 공개 소스, 배포 파일과 Git 기록을 대상으로 합니다. 새 파일은 두 공개 목록을 검토한 뒤 추가합니다. 각 PNG와 WebP는 허용된 경로, 이미지 구조, 해상도, 메타데이터 부재 및 검토한 파일의 SHA-256으로 확인합니다. 패턴 검사는 사람의 검토를 보완하는 수단입니다.

WEB LAB과는 사용자가 누르는 정적 링크로 연결합니다. 학습 앱의 계정이나 기록을 읽지 않습니다.

사이트는 외부 스크립트, 분석 도구, 웹 폰트와 로그인 기능을 사용하지 않습니다. HTML의 콘텐츠 보안 정책과 참조 주소 전송 제한을 적용했습니다. GitHub Pages의 응답 헤더 전체를 이 저장소에서 제어하는 것은 아닙니다.

공개 페이지는 검색 엔진에 노출될 수 있습니다. 수정 시에도 실험 조건과 현재 운영 상태를 유지하고, 로컬 시험 결과를 실제 사용자 서비스의 운영 지표로 바꾸지 않습니다.
