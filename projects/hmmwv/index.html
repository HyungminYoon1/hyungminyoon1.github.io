01 / 연구 질문

같은 질문에 교범이 있을 때와 없을 때

정비교범에는 비슷해 보이는 항목이 많아, 답변에 그럴듯한 단어가 나와도 질문의 조건에 맞는지 따져봐야 합니다. 같은 모델과 질문을 두고 한쪽에만 관련 교범 대목을 제공했습니다. 이렇게 자료를 찾아 답변에 쓰는 방식을 검색 증강 생성(RAG)이라고 합니다.

고정 실험 설정
항목설정
문서 범위공개 교범의 제1·2장에 해당하는 833쪽
검색 자료8,344개 청크, 청크당 최대 500토큰
검색BGE-M3, FAISS, 상위 5개
생성 모델Qwen3-4B-Instruct-2507 / Q4_K_M GGUF
질문과 실행60문항 × 2조건 × 3회차 = 360개 요청
내용 품질 분석첫 회차 120개 답변. 조건을 충분히 특정한 47문항을 주 분석

질문은 단일 근거 20문항, 다중 근거 30문항, 답변불가 10문항으로 구성했습니다. 답변 가능한 50문항 중 측정점, 장비나 시험 단계가 충분히 특정되지 않은 3문항은 조건부 참고로 분리했습니다. 같은 47문항을 주 분석에 사용하고, 답변불가 10문항은 별도로 검토했습니다.

02 / 처리 구조

교범을 검색 자료로 준비하고, 질문에 맞는 대목만 전달

교범 전체를 한 번에 모델에 넣는 대신 작은 조각인 청크로 나눴습니다. 문서와 질문의 의미를 숫자 벡터로 바꾸어 비교하고, 질문과 가까운 자료를 찾도록 구성했습니다.

정비 답변은 로컬 모델로 생성하고, 답변과 검색 자료를 저장했습니다. 저장된 답변은 별도의 평가 단계에서 원문과 대조했습니다.

같은 답변에 보완한 평가 기준을 적용했습니다

답변을 확인한 뒤 원문 근거와 필수 요소의 판정 기준을 보완해 다시 평가한 수치입니다. 생성 답변과 모델은 그대로 유지했고, 답변 전체는 AI로 검토했습니다. 외부 정비 전문가의 독립 검증은 후속 과제로 남아 있습니다.

04 / 오류 분석

근거가 있는 답변에도 필요한 내용이 빠졌습니다

주 분석에서 RAG 답변의 모든 주장이 원문으로 뒷받침되면서도, 질문에 필요한 내용 일부가 빠진 경우가 7개 있었습니다. 답한 내용이 맞는지와 필요한 내용을 빠짐없이 담았는지를 따로 확인했습니다.

서로 다르게 확인한 오류
구분확인한 문제
근거 확보질문에 필요한 근거를 검색했는가
답변의 근거 지지답변에 쓴 내용을 원문이 실제로 뒷받침하는가
필수 요소 충족수치 외에 액면 기준이나 적용 조건까지 답했는가
조건 적용제시된 수치 범위에 특정 값이 포함되는지 올바르게 판단했는가

검색의 평균 Recall@5는 78.0%였고, 50개 답변 가능 문항 중 필요한 근거를 모두 확보한 경우는 31개였습니다. 검색, 근거 해석, 필수 내용 누락을 나누어야 다음에 무엇을 바꿀지 정할 수 있었습니다.
